# سئوی HTML اولیه — ۲۸ اکتبر ۲۰۲۶

عنوان، توضیح، canonical، Open Graph، Twitter و دادهٔ ساختاریافتهٔ محصول اکنون در پاسخ اولیهٔ HTML تولید می‌شوند. خواننده بدون اجرای جاوااسکریپت هم آن‌ها را دریافت می‌کند. پس از اجرای React و جابه‌جایی مسیر، Helmet آن‌ها را جایگزین می‌کند؛ دو نسخهٔ متناقض باقی نمی‌ماند.

این تغییر رندر کامل بدنهٔ صفحات نیست؛ متن و فهرست محصولات داخل صفحه همچنان با React نمایش داده می‌شوند. کار روی محتوای دسته‌ها، رندر بدنه و سنجش واقعی سرعت هنوز باز است.

## رفتار و محدودیت‌ها
- محصول فعال با نام، توضیح، تصویر، قیمت ریالی و وضعیت موجودی خوانده می‌شود؛ هیچ امتیاز یا نقد ساختگی اضافه نمی‌شود.
- محصول ناموجود ۴۰۴ می‌گیرد. شکست موقت خواندن محصول ۵۰۳ با Retry-After: 30 می‌گیرد، تا قطعی به حذف محصول تعبیر نشود.
- مسیرهای شناخته‌شدهٔ حساب، مدیریت و پرداخت هم meta robots و هم X-Robots-Tag با noindex دارند. مسیر ناشناخته ۴۰۴ است. noindex جایگزین کنترل دسترسی نیست.
- HTML همچنان no-store است. Host، query، cookie و اطلاعات شخصی کاربر در metadata وارد نمی‌شوند. canonical به دامنهٔ ثابت jamimode.ir محدود است.
- خواندن محصول فقط GET ناشناس با کلید عمومی معتبر است؛ کلید service-role و نشست کاربر استفاده نمی‌شود. میزبان به پروژه‌های مجاز محدود است؛ بدنه حداکثر ۱۲۸ کیلوبایت و مهلت کل ۲٫۵ ثانیه است.
- کش درون پردازش: محصول ۳۰ ثانیه، نتیجهٔ ناموجود ۱۰ ثانیه، حداکثر ۲۰۰ ورودی و ۸ درخواست هم‌زمان. پس از تغییر قیمت/موجودی، metadata ممکن است تا ۳۰ ثانیه با خواندن تازهٔ رابط اختلاف داشته باشد. این کش روی مجوز خرید یا قیمت نهایی سفارش اثری ندارد.
- در محیط توسعهٔ Vite این middleware تولیدی فعال نیست؛ پذیرش HTML باید روی سرور build یا نسخهٔ منتشرشده انجام شود.

## شواهد
تمام ۱۶۳۱ آزمون واحد/یکپارچه و ۸۳ سناریوی مرورگر موفق‌اند؛ صفر شکست و صفر skip مرورگر. دو سناریوی جدید، محصول را با جاوااسکریپت خاموش و روشن بررسی می‌کنند. آزمون‌های سرور شامل وضعیت HTTP، مسیر خصوصی، فراردهی HTML/JSON-LD، محدودیت حجم/زمان، کش و سقف هم‌زمانی هستند.

خواندن عمومی و فقط‌خواندنی یک محصول از کاتالوگ اصلی نیز نام، قیمت و تصویر معتبر برگرداند؛ داده یا تنظیمی تغییر نکرد. build ایزوله و کنترل حجم موفق‌اند. پاسخ اولیهٔ JavaScript حدود ۸۱۷ کیلوبایت و gzip حدود ۲۴۸ کیلوبایت است؛ این اعداد زمان واقعی بارگذاری یا رتبهٔ جستجو را اثبات نمی‌کنند.

## پس از انتشار
HTML یک محصول، پاسخ ۴۰۴، هدرهای noindex و sitemap روی دامنه بررسی شوند. سپس URL Inspection و Rich Results در Search Console بررسی شوند. نتیجهٔ ایندکس و نمایش غنی تضمین‌شده نیست. Web Vitals، کیفیت محتوای دسته‌ها، تصاویر responsive و پایش واقعی هنوز کار دارند. این بسته هنوز commit یا منتشر نشده است.
