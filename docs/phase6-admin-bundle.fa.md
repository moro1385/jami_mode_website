# حذف runtime تکراری فرم محصول — ۳۱ اکتبر ۲۰۲۶

پس از بهینه‌سازی سبد، فرم محصول مدیر تنها مصرف‌کنندهٔ نسخهٔ کامل Zod در کد کاربردی باقی مانده بود. schema به domain کاتالوگ منتقل و با API سبک `zod/mini` همان نسخهٔ نصب‌شده بازنویسی شد. React Hook Form همچنان از zodResolver استفاده می‌کند. نگاشت انگلیسی خطا فقط به همان resolver داده می‌شود؛ تنظیم locale سراسری تغییر نکرد.

این تغییر قواعد فرم را اصلاح یا سخت‌گیرانه‌تر نمی‌کند: تبدیل تاریخی قیمت، حداقل صفر، پیام‌های سفارشی name/slug/price، مقدارهای پیش‌فرض boolean/array، فیلدهای nullable/optional و حذف کلیدهای اضافه حفظ شده‌اند. هیچ اعتماد تازه‌ای به قیمت مرورگر ایجاد نشده و هیچ مسیر نوشتن محصول/موجودی تغییر نکرده است. هیچ package یا lockfile تغییر نکرد.

| معیار | پیش از بهینه‌سازی سبد | پس از سبد | پس از فرم مدیر |
|---|---:|---:|---:|
| JS اولیه، بایت | 824707 | 791701 | 758485 |
| gzip اولیه، بایت | 250813 | 241097 | 232314 |
| chunk محصولات مدیر، حدود KB ده‌دهی | 124.47 | 161.53 | 127.14 |

کاهش نهایی ورودی اولیه: ۶۶۲۲۲ بایت خام، حدود ۸٪؛ ۱۸۴۹۹ بایت gzip، حدود ۷٫۴٪. مرحلهٔ دوم افزایش موقت chunk مدیر در مرحلهٔ اول را تقریباً برگرداند؛ chunk مدیر هنوز اندکی از نسخهٔ شروع بزرگ‌تر است و ادعای کاهش تک‌تک chunkها یا مجموع همهٔ مسیرها نمی‌شود. CSS و preload فونت ثابت‌اند. اندازه‌های قبل/بعد با build ایزولهٔ همان دستگاه اندازه‌گیری شدند، نه زمان شبکه.

بودجهٔ فعلی همان سقف سخت‌گیرانهٔ مرحلهٔ قبل، ۸۰۰۰۰۰ بایت خام و ۲۴۵۰۰۰ بایت gzip، است و خروجی جدید زیر هر دو سقف است. هشدار عمومی Vite برای chunk بیش از ۵۰۰KB همچنان وجود دارد؛ این تغییر Core Web Vitals را قبول‌شده اعلام نمی‌کند.

## بررسی‌ها

- ۲۲۴ آزمون تازه: مقایسه با schema قبلی برای نوع‌های نادرست، مقادیر پیش‌فرض/خالی/null، قیمت اعشاری/نامعتبر، booleanها و آرایه‌ها؛ مقایسهٔ مسیر/کد/متن خطا و خروجی resolver واقعی React Hook Form.
- ۲۰۴۲ آزمون واحد/یکپارچه در ۱۰۸ فایل موفق؛ ۲۲۴ مورد بالا در همین عدد شمرده شده‌اند.
- TypeScript، lint کامل، build ایزوله و کنترل بودجه موفق.
- آزمون محدود سرو فایل محلی با ۱۰۰ درخواست، چهار worker و صفر شکست موفق. این تست بار هاست نیست.

هر ۹۷ آزمون مرورگر روی خروجی نهایی، با API ساختگی، در حدود ۱۲۴٫۵ ثانیه موفق شدند؛ شکست، skipped و flaky صفر بود. فرم محصولِ ردشده و حفظ draft، بستن/بازکردن فرم هنگام save، ورود/حساب/سبد/checkout، نمایش مدیر و SEO در این اجرا پوشش داده شدند. هیچ commit، push، merge، deploy، تغییر هاست، SQL یا داده زنده در این بسته انجام نشده است. فایل‌های build ایزوله فقط برای آزمون‌اند و نباید منتشر شوند.

## وضعیت سایر کارها

پذیرش کشِ نسخه منتشرشده با خروجی موفق مالک بسته مانده است. گزارش واقعی Search Console برای هر دو دستگاه دادهٔ کافی ندارد؛ دادهٔ آزمایشگاهی معتبر دامنه، ظرفیت محیط میزبانی‌شده، پایش دائمی و نگهداری مرکزی لاگ هنوز تأیید نشده‌اند. کار محافظت GitHub مطابق درخواست تازهٔ مالک فعلاً کنار گذاشته شده است. این تغییرات به‌تنهایی کل فاز۶ را Done نمی‌کنند.

ابزارهای Notion و Windsor در فهرست ابزارهای این نشست حاضر نبودند، اگرچه فایل راهنمای مهارت‌شان موجود بود؛ هیچ وضعیت آنلاین تازه‌ای در Notion یا سرویس سئو ثبت یا خوانده نشد. یادداشت‌های این بسته محلی‌اند.
