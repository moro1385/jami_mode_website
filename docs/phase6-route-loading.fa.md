# بارگذاری صفحه‌ها، فاز ۶ — ۲۷ اکتبر ۲۰۲۶

## کار انجام‌شده
۱۵ صفحهٔ غیر از صفحهٔ اصلی، شامل فروشگاه، محصول، سبد، صفحات راهنما و مجموعه‌ها، با lazy و import پویا هنگام بازشدن مسیرشان دریافت می‌شوند. مسیرهای ورود، حساب، پرداخت و مدیریت قبلاً lazy بودند و حفظ شده‌اند. صفحهٔ اصلی مستقیم بارگذاری می‌شود.

Suspense داخل Layout، محل محتوای مسیر را پوشش می‌دهد؛ هنگام انتظار برای فایل صفحه، سربرگ، منو و پابرگ حذف نمی‌شوند. پیام فارسی با role=status و احترام به کاهش حرکت اضافه شده است. مرز خطای قبلی شکست دریافت chunk همچنان فعال است.

هیچ تنظیم دیتابیس، احراز هویت، پرداخت، CDN یا دروازهٔ فعال‌سازی تغییر نکرده است. dependency جدید یا تغییر قفل نسخه‌ها وجود ندارد. این بسته commit، push یا deploy نشده است.

## اندازه‌گیری قابل بازتولید
هر دو اندازه‌گیری با Vite تولیدی، تنظیم یکسان و محیط پاک‌سازی‌شدهٔ ساخت آفلاین انجام شده‌اند. جمع فایل ورودی و تمام importهای ثابت آن سنجیده شد؛ این صرفاً کوچک‌شدن یک فایل با انتقال اجباری به vendor نیست.

| معیار JavaScript اولیه | قبل، بایت | بعد، بایت | کاهش |
|---|---:|---:|---:|
| minified | 916588 | 816995 | 99593 (10.87٪) |
| gzip محلی | 273709 | 248443 | 25266 (9.23٪) |

گزارش ماشین‌خوان قبل و بعد کنار این سند نگهداری می‌شود. تصاویر، CSS، فونت‌ها و کدهای پویا در این عدد «JavaScript اولیه» نیستند؛ کل حجم تمام مسیرها لزوماً کمتر نشده است. صفحهٔ مقصد در اولین بازدید درخواست جداگانه دارد و بعد از بارگیری توسط React نگهداری می‌شود. سیاست cache سرور در این بسته تغییر نکرده است.

## اعتبارسنجی
- 1583 آزمون واحد/یکپارچه موفق و صفر شکست.
- تمام ۷۷ سناریوی مرورگر آفلاین موفق و بدون skip؛ ورود، خرید، رسید جعلی، سبد چندتب، مدیریت، موجودی، SEO و fallback خطای chunk را شامل می‌شوند.
- سه سناریوی جدید: صفحهٔ اصلی فایل Shop/ProductDetail/Contact/SizeGuide را درخواست نمی‌کند؛ با توقف عمدی فایل ProductDetail هنگام جابه‌جایی، صفحهٔ قبلی و سربرگ/پابرگ باقی می‌مانند و پس از آزادشدن درخواست، محصول نمایش داده می‌شود. در بازشدن مستقیم مسیر محصول، پیام انتظار دسترس‌پذیر همراه سربرگ/پابرگ دیده می‌شود. دوازده مسیر راهنما/مجموعه نیز مستقیماً باز و عنوانشان دیده شد.
- TypeScript، lint فایل‌های تغییرکرده و build ایزوله موفق. هشدار حجم فایل ورودی بالای ۵۰۰ کیلوبایت هنوز وجود دارد؛ پنهان نشده است.

## باقی‌مانده
فایل اولیه هنوز حدود ۸۱۷ کیلوبایت است و کتابخانه‌های مشترک احراز هویت، داده و رابط بخش بزرگی از آن هستند. اندازهٔ فایل جایگزین سنجش واقعی سرعت نیست: LCP، INP و CLS روی میزبان و اینترنت هدف اندازه‌گیری نشده‌اند. بررسی تصاویر/فونت، queryهای واقعی، cache/CDN و پذیرش پس از انتشار همچنان کار باز فاز ۶ هستند. موارد معوق لیارا، فعال‌سازی فاز ۵ و بررسی Search Console نیز به قوت خود باقی‌اند.

روش بارگذاری بر اساس [راهنمای رسمی React برای lazy و Suspense](https://react.dev/reference/react/lazy) و API موجود نسخهٔ نصب‌شده پیاده شده است.
