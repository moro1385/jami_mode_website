# جلوگیری از سنگین‌شدن مجدد خروجی — فاز ۶، ۲۸ اکتبر ۲۰۲۶

## پیاده‌سازی
ساخت‌های Vite عادی و ایزوله اکنون manifest تولید می‌کنند. دستور npm run check:build فایل ورودی index.html و تمام importهای ثابت آن را از این manifest پیمایش می‌کند. چرخه‌ها و فایل‌های مشترک دوباره شمرده نمی‌شوند؛ فایل‌های dynamic route که در بازدیدهای بعدی لازم‌اند در اندازهٔ اولیه نیستند. جابه‌جایی کتابخانه از entry به static vendor، عدد کل اولیه را کم نمی‌کند.

فایل config/build-budget.json سقف‌ها را نگه می‌دارد. این دستور در CI پس از build ایزوله اجرا می‌شود؛ عبور از هر سقف exit=1 و نبود/خرابی خروجی یا تنظیم exit=2 دارد. اجرای موفق exit=0 است. CI منتشرشده و branch protection هنوز تأیید نشده‌اند؛ این‌ها تغییر فایل workflow محلی هستند. فرمان معمول build در لیارا مستقل است و این کنترل را خودکار اجرا نمی‌کند.

| معیار | بایت فعلی | سقف بایت |
|---|---:|---:|
| JavaScript اولیه | 816952 | 850000 |
| gzip محلی JavaScript | 248433 | 260000 |
| CSS اولیه | 103914 | 200000 |
| فونت‌های preload | 49044 | 80000 |

این سقف‌ها محدودیت بازگشت به حجم بدتر هستند، نه معیار مطلوب نهایی یا تأیید سرعت واقعی. JavaScript هنوز بزرگ‌تر از هشدار پیش‌فرض ۵۰۰ کیلوبایت Vite است و آن هشدار حفظ شده است. زمان دانلود، cache/CDN، کیفیت تصاویر، همهٔ فونت‌های مصرفی CSS یا Web Vitals از این جدول نتیجه گرفته نمی‌شود. فایل فونت‌های فعلی با همان بستهٔ Vazirmatn FD نصب‌شده مطابقت دارد؛ فونت یا شکل ارقام عوض نشده است.

## بررسی‌ها
۱۲ آزمون جدید: پیمایش import مشترک/حلقوی، عدم شمارش dynamic import، حد خام/gzip، حذف تکرار CSS و preload، خطای manifest/فایل مفقود/تنظیم و رد مسیرهای traversal یا خارجی. همهٔ 1611 آزمون واحد/یکپارچهٔ پروژه موفق‌اند. TypeScript، lint کامل، build ایزوله، check:build و بررسی whitespace موفق‌اند.

در این تغییر کد رابط/سرور کاربردی تغییر نکرد؛ همان ۸۱ سناریوی مرورگر موفق بستهٔ قبلی شاهد رفتار برنامه‌اند و دوباره اجرا نشدند. فقط metadata ساخت و ابزار/تنظیم CI اضافه شد. audit قبلی پس از اصلاح qs صفر مورد بود؛ lockfile و dependencyها در این مرحله تغییر نکردند.

راهنمای انتشار، پذیرش و موارد باز همچنان docs/phase6-release.fa.md است. هیچ commit، push، deploy، SQL، تنظیم CDN یا برنامهٔ زمان‌بندی واقعی انجام نشده و کل فاز ۶ Done نیست.
