# کاهش JavaScript اولیه بدون تغییر قرارداد سبد — ۳۱ اکتبر ۲۰۲۶

اعتبارسنجی سبد در مسیر بارگذاری اولیه قرار دارد. import نسخهٔ کامل Zod باعث حضور بخش‌هایی از آن در فایل اصلی می‌شد، در حالی که قرارداد سبد فقط object/string/nullable، عدد صحیح مثبت تا ۱۰۰ و آرایه تا ۱۰۰ قلم را لازم دارد.

از `zod/mini` در همان نسخهٔ نصب‌شدهٔ ۴٫۶٫۷ استفاده شد؛ هیچ dependency یا lockfile تغییر نکرد. قواعد ورودی و خروجی حفظ شدند: تعداد صحیح ۱ تا ۱۰۰، حداکثر ۱۰۰ قلم، اندازه/رنگ nullable ولی الزامی، حذف فیلدهای اضافی، کپی مستقل price و رد کل سبد نامعتبر. اعتبار قیمت و موجودی برای پرداخت همچنان سمت سرور تعیین می‌شود؛ اعتبارسنجی محلی اختیار مالی ایجاد نمی‌کند.

| اندازه | پیش از تغییر | پس از تغییر | کاهش |
|---|---:|---:|---:|
| JS اولیه، بایت | 824707 | 791701 | 33006، حدود ۴٪ |
| gzip محلی، بایت | 250813 | 241097 | 9716، حدود ۳٫۹٪ |
| CSS اولیه، بایت | 104028 | 104028 | بدون تغییر |
| فونت preload، بایت | 49044 | 49044 | بدون تغییر |

نسخهٔ کامل Zod همچنان برای فرم محصول مدیر استفاده می‌شود و به chunk آن مسیر منتقل شده است: chunk فرم/صفحهٔ محصولات مدیر از حدود ۱۲۴٫۴۷ به ۱۶۱٫۵۳ کیلوبایت رسیده است. بنابراین کاهش فایل اولیه را کاهش قطعی مجموع کد همه مسیرها نمی‌نامیم. مسیر مدیر هنگام نیاز بارگیری می‌شود. این انتخاب به بازدید اولیهٔ فروشگاه کمک می‌کند، ولی افزایش سرعت واقعی مشتری یا امتیاز PageSpeed هنوز اندازه‌گیری نشده است.

سقف‌های CI برای جلوگیری از برگشت به حجم قبلی به ۸۰۰۰۰۰ بایت خام و ۲۴۵۰۰۰ بایت gzip کاهش یافتند؛ سقف CSS و فونت تغییر نکرد. هشدار Vite برای chunk بزرگ‌تر از ۵۰۰KB حفظ شده؛ عبور از بودجهٔ جدید به معنی سبک‌بودن ایده‌آل یا قبولی Core Web Vitals نیست.

## بررسی سازگاری

آزمون مقایسه‌ای، schema قبلی را فقط داخل test نگه می‌دارد و پذیرش/رد و فیلدهای خروجی را برای دادهٔ معتبر، null، نوع اشتباه، فیلد الزامی مفقود، قیمت ناقص، حد آرایه، اعشار/NaN/Infinity و تعداد بیش از سقف مقایسه می‌کند. schema قدیمی وارد فایل مرورگر نمی‌شود. همچنین استقلال snapshot و حذف فیلدهای اضافه بررسی شده‌اند.

اجرای کامل واحد/یکپارچه: ۱۸۱۸ آزمون در ۱۰۷ فایل موفق. TypeScript و lint کامل موفق؛ build ایزوله و کنترل حجم موفق. اجرای بار استاتیک محدود روی خروجی تازه: ۱۰۰ درخواست محلی با هم‌زمانی چهار و صفر شکست. زمان این آزمون ظرفیت هاست یا تأخیر اینترنت را نشان نمی‌دهد.

هر ۹۷ سناریوی مرورگر روی bundle تازه و APIهای ساختگی موفق شدند؛ ورود/حساب، سبد چندتب و قطع‌وصل، سفارش، مدیریت و SEO را پوشش می‌دهند. آزمون‌های ۱۲گانهٔ بودجه پس از سخت‌گیرانه‌ترشدن سقف نیز موفق‌اند و در ۱۸۱۸ آزمون واحد قبلی شمرده شده‌اند؛ این اعداد جمع نمی‌شوند. نتیجهٔ نهایی در ACCEPTANCE.json کنار گزارش محلی ثبت است. هیچ Migration، تغییر هاست/CDN، درخواست واقعی پرداخت، commit، push، merge یا deploy در این تغییر انجام نشده است. build ایزوله مخصوص تست است و بستهٔ انتشار نیست.
