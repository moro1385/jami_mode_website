# تصاویر و فونت: بارگذاری بخش اول صفحه — فاز ۶

## اصلاحات محلی، ۲۷ اکتبر ۲۰۲۶
- بنر اول صفحهٔ اصلی از پوشش FadeIn خارج شد؛ نمایش آن به callback مربوط به IntersectionObserver و افکت ۷۰۰ میلی‌ثانیه‌ای وابسته نیست. افکت بخش‌های پایین صفحه حفظ شده است.
- تصویر اول اسلایدر eager و دارای fetchpriority=high است؛ تصاویر اسلایدهای بعدی lazy و low هستند. این‌ها راهنمای مرورگرند و ترتیب قطعی دریافت را تضمین نمی‌کنند.
- تصویر اصلی صفحهٔ محصول eager/high است؛ بارگیری تنبل برای آن حذف شد. تصاویر کارت و مجموعه همچنان lazy هستند و decoding=async دارند. اندازهٔ فایل یا پیکسل‌های تصاویر تغییر نکرده است.
- فونت Regular با یک preload محلی معرفی شده؛ Vite آدرس آن را به همان فایل hashدار مورد استفادهٔ CSS تبدیل می‌کند. preconnect بلااستفادهٔ fonts.gstatic.com حذف شد. font-display:swap، شش وزن موجود و شکل فونت‌ها حفظ شده‌اند؛ همهٔ وزن‌ها preload نشده‌اند.
- یک ایراد واقعی گالری نیز اصلاح شد: کلیک روی thumbnail قبلاً src تصویر اصلی را به URL خام Supabase تغییر می‌داد. اکنون همان تابع supabaseAssetUrl، مسیر واسط سایت را برای انتخاب تصویر هم اعمال می‌کند. این اصلاح انتقال دیتابیس یا تغییر سیاست دسترسی نیست.

## شواهد
- 1583 آزمون واحد/یکپارچه موفق، صفر شکست.
- ۹ سناریوی متمرکز مرورگر موفق؛ سه آزمون جدید به همراه پرداخت، شبکهٔ واسط Supabase، SEO، محصول ناموجود و بارگیری مسیرها اجرا شدند. مجموعه اکنون ۸۰ سناریو دارد؛ همهٔ ۸۰ مورد در این مرحله دوباره اجرا نشده‌اند. اجرای کامل قبلی ۷۷/۷۷ پیش از این تغییرات ثبت شده است.
- دسکتاپ ۱۳۶۵×۹۰۰ و موبایل ۳۹۰×۸۴۴: با غیرفعال‌کردن عمدی callback observer، خود تصویر اول کامل بارگیری شده و هیچ ancestor با opacity=0 یا visibility=hidden ندارد. screenshot بنرها نیز بازبینی شد. بخش‌های پایین در این تصاویر آزمایشی به دلیل observer غیرفعال نمایان نیستند؛ این‌ها پیش‌نمایش کل صفحه نیستند.
- فونت Regular در مرورگر از فایل hashدار preload شد، CSS همان درخواست را استفاده کرد و درخواست تکراری برای آن ثبت نشد. font readiness نیز بررسی شد.
- گالری دو تصویر ساختگی از Storage: پس از انتخاب تصویر دوم، تصویر اصلی بارگیری شد و همهٔ درخواست‌های Storage روی مبدأ سایت با /api/supabase باقی ماندند؛ تماس مستقیم به میزبان Supabase دیده نشد.
- TypeScript، lint فایل‌های تغییرکرده، build ایزوله و بررسی whitespace موفق‌اند. هشدار اندازهٔ JavaScript اولیه هنوز باز است؛ این مرحله کاهش تازه‌ای برای حجم bundle یا تصویر ادعا نمی‌کند.

## محدودیت‌ها و ادامه
این‌ها اصلاح اولویت/نمایش و مسیر دریافت هستند؛ کاهش زمان واقعی LCP/INP/CLS روی اینترنت ایران و هاست اندازه‌گیری نشده است. فایل تصویر اصلی بنر هنوز حدود ۲۶۰ کیلوبایت است. اندازه‌های responsive، بازفشرده‌سازی تصاویر، lazy loading درخواست‌های کاتالوگ و cache/CDN کارهای جداگانه‌اند؛ در این بسته انجام نشده‌اند. preload روی همهٔ مسیرها فقط فونت معمولی مشترک را درخواست می‌کند و وزن‌های دیگر همچنان برحسب نیاز مرورگر دریافت می‌شوند.

هیچ commit، push، deploy، SQL یا تغییر تنظیمات میزبانی انجام نشد. فعال‌سازی معوق فاز ۵، پذیرش لیارا و بررسی‌های نسخهٔ منتشرشده همچنان بازند. کل فاز ۶ تکمیل اعلام نمی‌شود.

منابع: [اولویت دریافت منابع](https://web.dev/articles/fetch-priority)، [بارگذاری فونت](https://web.dev/articles/font-best-practices) و [دارایی‌های hashدار در Vite](https://vite.dev/guide/assets.html). پیاده‌سازی بر اساس نسخه‌های نصب‌شده نیز با build و مرورگر بررسی شد.
