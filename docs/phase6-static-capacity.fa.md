# آزمون ظرفیت محدود بخش استاتیک — ۳۰ اکتبر ۲۰۲۶

```sh
npm run build:isolated
node scripts/check-static-capacity.mjs
```

ساخت ایزوله برای آزمون است و نباید به‌عنوان بستهٔ انتشار استفاده شود. ابزار، خروجی پوشهٔ dist را با middleware واقعی `createStorefrontStatic` روی پورت تصادفی 127.0.0.1 سرو می‌کند. آدرس مقصد، تعداد درخواست و هم‌زمانی ورودی قابل تغییر ندارند: دقیقاً ۱۰۰ درخواست با چهار worker، پس از شش بررسی پایهٔ هدر. هیچ API، دیتابیس، پرداخت، سرویس پیامک یا هدف بیرونی فراخوانی نمی‌شود. listener در پایان بسته می‌شود؛ فایل و داده‌ای پاک یا درج نمی‌شود.

پنج مسیر خانه، پوستهٔ عمومی حساب، JS و CSS واقعیِ اشاره‌شده در HTML و فایل ناموجود، هرکدام ۲۰ نمونه دارند. بدنه‌ها کامل و تا سقف پنج مگابایت برای هر پاسخ خوانده می‌شوند؛ پاسخ‌ها مهلت پنج‌ثانیه‌ای دارند. خروجی فقط تعداد، حجم و زمان تجمیعی دارد؛ HTML/کوکی/شناسهٔ کاربر ثبت نمی‌شود.

معیار `ok` موفقیت همهٔ پاسخ‌های مورد انتظار است. p50/p95/max و نرخ درخواست تنها توصیف همان اجرای محلی‌اند؛ آستانهٔ زمان وابسته به سخت‌افزار در CI تحمیل نشده است. نتیجهٔ این ابزار اثبات ظرفیت لیارا، تأخیر اینترنت، بار دیتابیس، مرورگر، LCP/CLS/INP یا تحمل حمله نیست. رسیدن به سقف ۱۰۰ درخواست در loopback، جای تست بار نماینده در محیط کنترل‌شده را نمی‌گیرد.

اولین اجرا روی خروجی موجود: ۱۰۰ درخواست، صفر شکست، ۱۷۰ میلی‌ثانیه کل؛ p95 خانه ۶٫۵۳ms، حساب ۹٫۶۶ms، JS برابر ۲۳٫۵۳ms و CSS برابر ۱۰٫۴۱ms. فایل JS در هر درخواست کامل منتقل شد؛ مجموع حجم حدود ۱۸٫۶۵MB بود. این اعداد warm/local و فقط یک اجرا هستند؛ با سرعت تجربهٔ مشتری مقایسه نمی‌شوند.

مرحلهٔ CI پس از build ایزوله و کنترل بودجه اضافه شده است. اجرای آنلاین workflow به انتشار این بسته و CI بعدی وابسته است؛ نصب‌شده یا موفق‌شدهٔ آنلاین ادعا نمی‌شود.

## سنجش مرورگر و گوگل

یک مرورگر headless با context خالی برای خانه راه‌اندازی شد؛ اتصال قبل از دریافت صفحه شکست خورد و اجرای دوم انجام نشد. هیچ عدد LCP/CLS/INP از آن گزارش نمی‌شود.

گزارش واقعی Search Console در همان حساب مالک خوانده شد: Core Web Vitals با آخرین به‌روزرسانی ۲۹ اکتبر ۲۰۲۶، برای هر دو Mobile و Desktop پیام «Not enough usage data in the last 90 days for this device type» نشان می‌دهد. این شاهد نبود داده کافی است، نه قبولی یا رد سرعت. طبق [راهنمای گوگل](https://support.google.com/webmasters/answer/9205520?hl=en)، گزارش بر تجربه کاربران واقعی متکی است؛ [اندازه‌گیری آزمایشگاهی](https://web.dev/articles/vitals) جای آن داده را نمی‌گیرد.

سنجش آزمایشگاهی معتبر دامنه و تست بار محیط میزبانی‌شده همچنان بازند. موفقیت پذیرش کشِ اعلام‌شده توسط مالک محفوظ است و دوباره باز نشده است.
