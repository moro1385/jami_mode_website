# بررسی سئوی نسخهٔ منتشرشده — ۲۸ اکتبر ۲۰۲۶

ابزار scripts/check-site-seo.mjs یک اجرای فقط‌خواندنی با حداکثر هفت درخواست GET است. به کلید، حساب، نشست مرورگر یا دسترسی دیتابیس نیاز ندارد. صفحه‌ای را ویرایش نمی‌کند و به موتور جستجو چیزی ارسال نمی‌کند.

از پوشهٔ مخزن و پس از انتشار کد اجرا کنید:

    node scripts/check-site-seo.mjs

خروجی JSON است؛ result برابر ok فقط یعنی بررسی‌های محدود این اجرا موفق بوده‌اند. needs_review نیاز به بررسی دارد؛ نام بررسی و reason علت را نشان می‌دهد. exit code صفر موفق، یک نیازمند بررسی و دو ورودی نامعتبر است. راهنما با --help نمایش داده می‌شود. اجرا، زمان‌بندی یا هشدار خارجی نصب نشده است.

## دامنهٔ بررسی
- robots.txt: وجود گروه User-agent عمومی، نبود منع ریشه در آن گروه و اعلام sitemap دامنهٔ اصلی. این بخش جایگزین مفسر کامل تمام قواعد robots نیست.
- sitemap.xml: ساختار تخت تولیدشدهٔ همین پروژه، حضور ۱۳ صفحهٔ عمومی، نبود آدرس تکراری، خصوصی، خارجی، query یا fragment. سقف ۱۰٬۰۱۳ آدرس و ۲ مگابایت؛ بدون دنبال‌کردن sitemap یا آدرس خارجی. dialectهای دیگر XML، sitemap index، namespace متفاوت و entityها پذیرفته نمی‌شوند.
- صفحهٔ اصلی و فروشگاه: عنوان و توضیح غیرخالی و یکتا، robots صحیح و canonical و og:url مطابق دامنهٔ ثابت اصلی در HTML اولیه.
- حساب: noindex در HTML و هدر و نداشتن canonical عمومی؛ هیچ ورود یا اطلاعات حساب خوانده نمی‌شود.
- مسیر ناموجود ثابت: وضعیت ۴۰۴ و noindex، بدون canonical عمومی.
- اولین محصول نقشهٔ سایت: HTTP موفق، metadata و یک Product JSON-LD با نام، قیمت ریالی مثبت، موجودی معتبر و آدرس canonical صحیح.

## محدودیت و امنیت اجرا
مقصد به دامنهٔ اصلی/WWW یا loopback در پورت‌های مجاز ابزار سلامت محدود است. WWW باید بدون redirect پاسخ مورد انتظار بدهد؛ هدایت دنبال نمی‌شود و به‌صورت نیازمند بررسی گزارش می‌شود. canonical همچنان jamimode.ir است. مسیر محصول فقط پس از پذیرش تمام نقشهٔ سایت انتخاب می‌شود. اطلاعات احراز هویت ارسال نمی‌شود. برای هر درخواست مهلت کل ۶ ثانیه شامل خواندن بدنه وجود دارد؛ HTML حداکثر ۲۵۶ کیلوبایت، robots حداکثر ۳۲ کیلوبایت است. پاسخ خام، نام محصول و خطای داخلی در گزارش چاپ نمی‌شوند.

ابزار یک محصول را نمونه‌برداری می‌کند و مرورگر اجرا نمی‌کند. سلامت همهٔ محصولات، ایندکس واقعی، رتبه، Rich Results، کیفیت محتوا، قوانین کامل robots و Web Vitals را اثبات نمی‌کند. شکست شبکه از این کامپیوتر شاهد قطعی جهانی نیست. گزارش نسخهٔ قدیمی می‌تواند نیازمند بررسی باشد؛ پذیرش این اصلاحات باید پس از انتشار همان کد انجام شود.

## شواهد محلی
۱۹ آزمون جدید موفق‌اند؛ شامل HTTP واقعی با middleware تولیدی و کاتالوگ ساختگی، آدرس خارجی و خصوصی در sitemap، تکرار metadata، هدایت، header اشتباه، پاسخ بزرگ، transport متوقف و پاک‌ماندن خروجی از جزئیات خطا. کل 1653 آزمون واحد/یکپارچه موفق شد. TypeScript و lint موفق‌اند. آخرین اجرای کامل مرورگر مرحلهٔ قبلی ۸۵ سناریوی موفق بود؛ در این مرحله کد رابط، build و middleware تولیدی تغییر نکرد و آن اجرای مرورگر تکرار نشد.

این ابزار روی دامنهٔ زنده اجرا نشده؛ دادهٔ ساختگی آزمون، پذیرش انتشار نیست. commit، push، merge، deploy و تغییر داده/تنظیمات میزبانی انجام نشده‌اند. ابزار طبق .liaraignore فعلی در بستهٔ اجرایی میزبان قرار نمی‌گیرد و از checkout محلی اجرا می‌شود.

## افزودهٔ BreadcrumbList
بررسی محصول اکنون دقیقاً یک Product و یک BreadcrumbList را انتظار دارد و ترتیب، نام و آدرس خانه/فروشگاه/محصول را بررسی می‌کند. این ابزار را فقط همراه نسخهٔ همسان کد و schema به کار ببرید؛ نسخهٔ منتشرشدهٔ قدیمی ممکن است نیازمند بررسی گزارش شود.
