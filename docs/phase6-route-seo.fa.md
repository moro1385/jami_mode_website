# هماهنگی مسیرها و توضیح صفحات — ۲۸ اکتبر ۲۰۲۶

## تغییر این مرحله
۱۳ صفحهٔ عمومی اکنون توضیح اختصاصی دارند که در یک منبع مشترک نگهداری می‌شود. پاسخ اولیهٔ سرور و metadata پیش‌فرض React از همان منبع استفاده می‌کنند. توضیحات اختصاصی قبلی صفحهٔ اصلی، دربارهٔ ما، تماس، پرسش‌ها و فروشگاه حفظ شده‌اند. توضیح فیلترهای فروشگاه همچنان در رابط پویا است؛ canonical همهٔ فیلترها همچنان /shop است. این مرحله برای فیلترهای فروشگاه صفحهٔ مستقل قابل ایندکس ایجاد نمی‌کند.

محصول ناموجود پیش‌تر با Navigate به فروشگاه منتقل می‌شد. اکنون در همان آدرس، پیام روشن و لینک اختیاری فروشگاه نمایش داده می‌شود. وضعیت پاسخ اولیهٔ محصول ناموجود ۴۰۴ است؛ پس از اجرای JavaScript نیز noindex باقی می‌ماند و canonical، og:url و schema محصول حذف می‌شوند. خطای خواندن اطلاعات از ناموجودبودن جدا است و امکان تلاش دوباره دارد. وضعیت HTTP در جابه‌جایی داخلی React قابل تغییر نیست؛ درخواست مستقیم از سرور وضعیت درست را دریافت می‌کند.

RouteSEO در مسیر معتبر محصول، مدیریت metadata را به صفحهٔ محصول واگذار می‌کند تا canonical پیش‌فرضِ والد در حالت ناموجود باقی نماند. برچسب‌های محصول موجود با JavaScript خاموش و روشن بررسی شده‌اند. مسیر راهنمای قابل مشاهدهٔ محصول نیز نام دسترس‌پذیر و aria-current دارد؛ BreadcrumbList ساختاریافته در این مرحله اضافه نشده است.

آدرس /index.html با ۳۰۸ به / می‌رود تا نسخهٔ هم‌معنای صفحهٔ اصلی به مسیر ناشناختهٔ React تبدیل نشود. مقصد ثابت است و query ورودی را بازتاب نمی‌دهد؛ پاسخ هدایت no-store است.

## اعتبارسنجی
1634 آزمون واحد/یکپارچه و 85 آزمون مرورگر موفق؛ صفر شکست، skip و flaky. TypeScript، lint، build ایزوله و کنترل حجم موفق. چهار سناریوی مرورگر SEO شامل HTML بدون JavaScript، محصول موجود پس از اجرای برنامه، ناموجودبودن و برگشت به فروشگاه، و تطبیق توضیح چهار صفحه پیش و پس از اجرای برنامه است. سقف‌های build رعایت شدند؛ JavaScript اولیه 818760 بایت و gzip 248983 بایت است.

آزمون مرورگر ابتدا باقی‌ماندن canonical والد را پیدا کرد؛ اصلاح و build تازه انجام شد و اجرای نهایی موفق است. هیچ تغییر دیتابیس، commit، push، merge یا انتشار انجام نشده. پذیرش روی دامنه، Search Console، رندر بدنهٔ صفحات و اندازه‌گیری واقعی سرعت همچنان باز است.
