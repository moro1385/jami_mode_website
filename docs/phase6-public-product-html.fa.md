# محتوای خواندنی محصول در HTML اولیه — ۲۸ اکتبر ۲۰۲۶

نام، توضیح کامل، قیمت ریالی، وضعیت موجودی عمومی، مسیر راهنما و تصویر عمومی معتبر محصول اکنون داخل بدنهٔ پاسخ اولیه نیز قرار می‌گیرند. مرورگر با JavaScript خاموش می‌تواند این اطلاعات را بخواند. داده از همان خواندن عمومیِ قبلی metadata می‌آید؛ برای اضافه‌کردن این محتوا، درخواست دیتابیس دیگری فرستاده نمی‌شود. این خروجی برای همهٔ مراجعه‌کنندگان یکسان است و تشخیص ربات/User-agent ندارد.

خطای ۴۰۴ و ۵۰۳ نیز متن خواندنی و لینک فروشگاه دارند و وضعیت HTTP، noindex و Retry-After قبلی حفظ شده‌اند. حساب، مدیریت و پرداخت در بدنهٔ اولیه دادهٔ کاربر یا خلاصهٔ محصول ندارند. قالب از cookie یا نشست درخواست استفاده نمی‌کند.

## راه‌اندازی برنامه و محدودیت
createRoot فعلی React پس از اجرای برنامه، خلاصهٔ اولیه را جایگزین می‌کند. آزمون مرورگر حذف marker خلاصه و ظاهرشدن صفحهٔ عادی با یک h1، canonical و هر schema را بررسی کرد. انتخاب سایز، سبد و خرید از همان برنامهٔ تعاملی انجام می‌شود؛ فرم/دکمهٔ خرید بدون اعتبارسنجی به HTML اولیه اضافه نشده. برای JavaScript خاموش، پیام راهنمای فعال‌سازی نمایش داده می‌شود.

این کار hydration یا SSR کامل React نیست. در حین راه‌اندازی، امکان نمایش وضعیت بارگذاری قبلی بین خلاصه و صفحهٔ تعاملی وجود دارد. بهبود LCP/CLS یا رتبهٔ جستجو اندازه‌گیری یا تضمین نشده است. بدنهٔ خانه، مجموعه‌ها، فروشگاه و صفحات اطلاعاتی همچنان به React وابسته است. پیاده‌سازی hydration یکپارچه و پذیرش میزبانی هنوز باز هستند.

قیمت و موجودیِ اولیه از کش عمومی قبلی با مهلت ۳۰ ثانیه می‌آیند و ممکن است پس از ویرایش مدیریت، با خواندن تازهٔ مرورگر موقتاً اختلاف داشته باشند. قیمت نهایی سفارش همچنان سروری است. تصویر همان پروژه از مسیر نسبی relay خوانده می‌شود. عکس نامعتبر/placeholder از خلاصه حذف می‌شود؛ هیچ تصویر جایگزین ساختگی اضافه نمی‌شود.

## فراردهی و بررسی خودکار
متن محصول در HTML فراردهی می‌شود؛ توضیح محصول به‌عنوان HTML اجرا نمی‌شود. جای‌گذاری head نیز به callback تبدیل شد تا توالی‌های جایگزینی JavaScript مثل $&، $` و $' در دادهٔ محصول باعث بازدرج بخش‌های قالب نشوند. آزمون نام دارای این توالی‌ها و پایان script موفق است. این اصلاح ادعای تأیید کل امنیت سایت نیست.

ابزار check-site-seo اکنون علاوه بر metadata و Product/BreadcrumbList، h1 و قیمت/موجودی قابل‌مشاهده را با دادهٔ ساختاریافته تطبیق می‌دهد؛ وجود صرف metadata برای پذیرش نمونهٔ محصول کافی نیست.

## شواهد
کل 1681 آزمون واحد/یکپارچه موفق. شش سناریوی مرتبط مرورگر موفق، بدون شکست/skip/flaky: محصول با JavaScript روشن/خاموش، هماهنگی metadata عمومی، محصول ناموجود پس از اجرای برنامه و متن ۴۰۴/۵۰۳ بدون JavaScript. آخرین اجرای کامل ۹۳ سناریوی مرورگر مربوط به بستهٔ r8 بود؛ در این مرحله فقط شش سناریوی سرور/SEO اجرا شد.

TypeScript، lint و diff check موفق‌اند. ورودی برنامه و CSS/build مرورگر تغییر نکرده‌اند؛ build دوباره انجام نشد و گزارش حجم بستهٔ r8 با همین محدوده نگهداری شده است. خوانایی نمونهٔ ساختگی بدون تصویر در ۱۲۸۰×۹۰۰ و ۳۹۰×۸۴۴ مشاهده شد؛ overflow افقی نداشت. تصویر عمومی معتبر و فراردهی آن در آزمون سرور بررسی شدند.

خوانندهٔ عمومی و query قبلی تغییر نکردند؛ آزمون‌های خواندن عمومی پیشین همچنان سوابق همان اجرا هستند. روی دامنهٔ زنده انتشار یا پذیرش تازه انجام نشده. commit، push، merge، deploy و SQL انجام نشده‌اند.
